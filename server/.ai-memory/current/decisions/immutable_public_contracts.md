category: decisions
confidence: high
stability: high
tags: contract-stability, immutability, governance
---
Rule
Core API signatures, data schemas, and workflow steps are immutable versioned agreements; deviations require formal impact analysis and stakeholder sign‑off.
Rationale
Preserve system stability and prevent cascading failures from unconstrained modifications.
Applies to
All system interfaces, data models, and inter‑module communication protocols.
Constraints
No deviation without documented multi‑stakeholder review.
