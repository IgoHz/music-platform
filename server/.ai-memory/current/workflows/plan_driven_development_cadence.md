category: workflows
confidence: high

---
Rule
Implementation is permitted only after a documented design artifact receives formal approval; no code may be committed without an associated approved plan.
Rationale
Prevent unchecked feature sprawl and align engineering effort with validated designs.
Applies to
All non‑trivial feature implementation and significant architectural changes.
Constraints
Code commits must map directly to steps in the approved design plan.
